    Kali Linux Windows Substitute

    A Kali-style workbench for Windows. The tools are the real Linux tools running in the app's own private WSL2 runtime, not recompiled Windows copies. Start with a tool below; each one tells you what it needs and lets you install it on demand.

    Record findings as you go, ask the optional AI to explain output, and export a report. The workbench itself stays on your machine; installing tools on demand needs an internet connection.
